# Worship Unscripted Birmingham

A modern Next.js website for an independent interdenominational worship movement in Birmingham, UK.

## Getting started

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository in Vercel, choose Next.js, and deploy. The public site is currently a launch-stage landing page. Registration, mailing lists, admin access, and confirmed venue/date details are not yet implemented. Do not publish placeholder dates or accept registrations until those systems are ready.
